# 一期联调验收与发布准备

## 1. 文档目的

本文档用于对一期目标“白模渲染节点真实运行”进行验收收口，明确：

- 当前一期验收范围
- 已完成的自动化验证
- 仍需执行的真实人工联调项
- 当前可交付结论
- 已知问题与发布前注意事项

本文档对应的一期唯一业务边界文档为：

- `backend/docs/WHITE-MODEL-RENDER-V1.md`

## 2. 一期验收目标

一期验收目标不是完成完整后端平台，而是确认以下链路已经具备可交付条件：

1. 前端白模渲染节点可以提交 grouped 输入
2. 后端可以接收输入文件并创建真实执行任务
3. Worker 可以按三阶段流程执行：
   - 线稿图生成
   - 深度图生成
   - 最终图生成
4. 同一张白模图的中间产物可以复用
5. grouped 多任务可以并发执行
6. 失败任务可以按规则自动重试
7. 最终结果、步骤事件、错误信息可查询

## 3. 最小联调环境变量

一期最小联调环境变量如下：

```env
NODE_ENV=development
BACKEND_HOST=127.0.0.1
BACKEND_API_PORT=3100
BACKEND_WORKER_PORT=3200
BACKEND_WORKER_POLL_INTERVAL_MS=5000
BACKEND_PROVIDER_SNAPSHOT_DIR=data/provider-snapshots
LAOZHANG_API_KEY=你的真实老张 API Key
LAOZHANG_API_URL=https://api2.laozhang.ai/v1beta/models/gemini-3-pro-image-preview:generateContent
```

说明：

1. 本地自动化测试不依赖真实 `LAOZHANG_API_KEY`
2. 真实人工联调必须填写有效 `LAOZHANG_API_KEY`
3. 一期默认使用本地文件存储与本地快照目录
