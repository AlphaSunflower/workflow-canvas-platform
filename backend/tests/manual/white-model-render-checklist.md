# 白模渲染节点一期手工联调清单

## 1. 联调前准备

- 已在 `backend/.env.example` 对应环境中填写真实 `LAOZHANG_API_KEY`
- API 服务可启动
- Worker 服务可启动
- 前端已连接到真实后端接口
- 已准备至少 2 组测试输入

## 2. 测试输入建议

### 输入组 1

- 白模图 A
- 风格参考图 A

### 输入组 2

- 白模图 A
- 风格参考图 B

要求：

- 两组必须使用同一张白模图 A
- 第二组用于验证中间产物缓存复用

## 3. 手工检查项

### 3.1 文件注册链路

- 前端执行前先上传或注册输入文件
- 后端成功返回 `fileId`
- 相同白模图重复使用时不需要重复上传物理文件

### 3.2 单组真实成功链路

- 提交输入组 1
- 任务进入排队或执行状态
- 线稿图生成成功
- 深度图生成成功
- 最终图生成成功
- 最终产物可回写到前端节点

### 3.3 缓存复用链路

- 提交输入组 2
- 观察是否命中输入组 1 的线稿图缓存
- 观察是否命中输入组 1 的深度图缓存
- 最终图仍正常生成

### 3.4 grouped 多任务并发链路

- 一次提交至少 2 个 group
- 后端为多个 group 创建独立任务
- 多个 group 可并发执行
- 一个 group 的执行不会阻塞另一个 group 的完成

### 3.5 重试与失败链路

- 人为制造一个老张 API 失败场景
- 观察是否自动重试两次
- 观察前端是否显示 attempt 与重试进度
- 三次均失败时是否进入最终失败

### 3.6 查询与结果链路

- 可查询 run 级状态
- 可查询 task 级状态
- 可查询步骤事件
- 可查询最终结果文件引用
- 失败时可查询错误码与错误信息
