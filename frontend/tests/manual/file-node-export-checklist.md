# 文件节点保存导出手动验收清单

## 目标

确认 `image` / `video` / `ply` 文件节点在本地文件、后端产物、目录写入、下载降级场景下都能稳定导出，不出现错内容、错文件名或静默失败。

## 验收前准备

- 启动前端开发环境
- 至少准备 1 张本地图片、1 个本地视频、1 个本地 `ply` 文件
- 至少准备 1 个由后端执行生成的图片产物节点
- 至少准备 1 个由后端执行生成的视频或模型产物节点
- 如需验证目录写入，使用支持 `showDirectoryPicker` 的浏览器环境

## 核心场景

### 1. 本地图片文件节点

- 导入本地图片，生成图片文件节点
- 点击节点右上保存按钮
- 预期：可保存到选定目录或降级浏览器下载
- 预期：导出内容为原始图片，不是低清预览图
- 预期：导出文件名带正确图片扩展名

### 2. 本地视频文件节点

- 导入本地视频，生成视频文件节点
- 点击保存按钮
- 预期：导出内容为原始视频文件
- 预期：导出文件名带正确视频扩展名

### 3. 本地 ply 文件节点

- 导入本地 `ply` 文件，生成模型文件节点
- 点击保存按钮
- 预期：导出内容为原始 `ply` 模型文件
- 预期：导出文件名以 `.ply` 结尾

### 4. 后端图片产物节点

- 运行一个能产出图片的真实后端节点
- 等待产物节点生成
- 点击保存按钮
- 预期：优先导出后端原图 `/download`
- 若原图不可用：预期回退到可访问的预览图，并给出合理成功结果

### 5. 后端视频产物节点

- 运行一个能产出视频的真实后端节点
- 点击保存按钮
- 预期：导出内容来自后端 `/download`
- 预期：不会错误导出预览帧或缩略图

### 6. 后端 ply 产物节点

- 运行一个能产出 `ply` 的真实后端节点
- 点击保存按钮
- 预期：导出内容来自后端 `/download`
- 预期：不会错误导出图片或占位内容

### 7. 右键菜单入口

- 对任意文件节点打开右键菜单
- 点击“保存到目录”
- 预期：触发与按钮相同的导出能力
- 预期：强制拉起目录选择器

### 8. 下载降级

- 在不支持目录选择能力的环境中点击保存
- 预期：自动降级为浏览器下载
- 预期：提示语义为“已降级下载”，不是“保存失败”

### 9. 文件名修正

- 准备无扩展名、错误扩展名、重复扩展名、带非法字符的节点文件名
- 点击保存
- 预期：导出文件名被自动清洗并修正为正确扩展名

### 10. 异常提示

- 模拟后端 `/download` 失败
- 模拟图片原图和预览兜底都不可用
- 点击保存
- 预期：收到明确错误提示，不是泛化“导出失败”
