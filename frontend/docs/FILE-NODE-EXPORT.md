# 文件节点保存导出规范

## 1. 目标

本规范用于冻结前端文件节点保存导出能力的一期范围，明确统一入口、目录写入策略、降级策略、文件类型覆盖范围与不做项。

本期目标不是为单个节点补一个临时下载按钮，而是为所有文件节点建立统一、可复用、可扩展的导出能力。

## 2. 适用范围

本规范适用于前端画布中的全部文件节点：

- `image`
- `video`
- `ply`

无论文件节点来自以下哪种来源，均应统一接入保存导出能力：

- 本地导入文件节点
- 后端执行结果回写生成的产物节点
- 工作流归档恢复后的文件节点

## 3. 统一交互入口

本期统一采用以下两个入口：

- 文件节点本体内的保存按钮
- 文件节点右键菜单中的“保存到目录”

约束如下：

- 文件节点保存能力必须通过共享文件节点组件接入
- 不允许在各个具体 AI 节点组件中单独实现保存导出逻辑
- 两个入口必须复用同一套保存导出服务，不允许分别维护不同实现

## 4. 保存策略

### 4.1 主策略

当运行环境支持浏览器目录访问能力时，前端应优先执行“保存到指定目录”：

- 首次保存时由用户选择目标目录
- 当前会话内后续保存可复用已授权目录句柄
- 导出时直接将目标文件写入用户选择的目录

### 4.2 降级策略

当运行环境不支持目录访问能力，或目录权限不可用时，前端必须自动降级为普通浏览器下载：

- 仍然允许用户完成文件保存
- 但不保证写入用户指定目录
- 前端必须明确提示当前为降级下载，而不是目录写入

### 4.3 当前会话规则

目录句柄在本期仅允许当前会话内复用：

- 页面刷新后不保证保留目录授权
- 不做跨会话目录记忆
- 不做目录句柄持久化恢复

## 5. 文件内容导出规则

### 5.1 图片节点

图片节点导出必须遵循以下优先级：

1. 优先导出原图
2. 若原图不可用，才允许按既定兜底规则导出可访问的图片资源
3. 不允许默认导出预览图替代原图

说明：

- “原图”优先包括本地原始文件或后端结果原始下载文件
- 预览图只可作为异常场景下的兜底，不可作为默认输出
- 当后端 `/download` 与图片 original URL 均不可用时，可回退 `previewUrl` / `thumbnailUrl`
- 当原图与所有兜底资源均不可用时，必须明确提示图片资源缺失，不允许静默失败

### 5.2 视频节点

视频节点必须导出原始视频文件，不做转码，不导出预览帧，不导出缩略图。

### 5.3 PLY 节点

`ply` 节点必须导出模型本体文件，不允许替换为截图、预览图或其他中间格式。

## 6. 命名与扩展名规则

文件导出时必须保证输出文件具备稳定、可用的文件名：

- 优先使用节点当前文件名
- 文件名缺失扩展名时，需基于 MIME 或文件类型补齐
- 文件名扩展名与 MIME 不匹配时，按 MIME 与节点类型修正
- 文件名存在重复扩展名时，只保留一份最终扩展名
- 文件名含非法路径字符时，需做统一清洗
- 不允许导出无扩展名、错误扩展名或明显不可用的文件名

补充规则：

- `image` 缺失或错误扩展名统一回退到真实图片 MIME，对应缺省扩展名为 `png`
- `video` 缺失或错误扩展名统一回退到真实视频 MIME，对应缺省扩展名为 `mp4`
- `ply` 缺失或错误扩展名统一修正为 `ply`

## 7. 架构边界

本期必须建立统一文件导出服务，并冻结以下职责边界：

- 文件节点组件只负责触发保存动作与展示结果
- 文件内容解析、目录选择、权限校验、文件写入、下载降级必须由统一导出服务负责
- 本地文件、远端文件、归档恢复文件的读取路径必须统一收敛到公共服务中

## 8. 错误与提示规则

前端必须能区分以下结果类型并向用户给出明确反馈：

- 保存到目录成功
- 降级为浏览器下载成功
- 目录授权失败
- 文件内容不存在
- 文件读取失败
- 文件写入失败
- 远端 `/download` 请求失败
- 图片原图缺失且预览兜底也失败

不允许出现只提示“保存失败”但无上下文的泛化提示。

## 9. 本期不做项

以下能力明确不在本期范围内：

- 批量导出多个文件节点
- 跨会话记忆上次选择目录
- 后端统一打包导出
- 各节点自定义专属导出逻辑
- 导出前的格式转换、压缩、转码
- 导出历史记录与导出任务中心

## 10. 验收口径

本规范对应的一期验收口径如下：

- 所有 `image` / `video` / `ply` 文件节点都存在统一保存导出入口
- 目录写入可用时，文件可保存到用户指定目录
- 目录写入不可用时，系统会自动降级为浏览器下载
- 图片节点默认导出原图，视频节点导出原视频，`ply` 节点导出模型文件
- 文件节点保存能力不依赖具体 AI 节点实现，后续新增节点无需重复开发保存逻辑

- 浏览器下载降级路径
- 本地文件与后端产物两类来源
- `image` / `video` / `ply` 三类文件类型
- 文件名清洗与扩展名修正
